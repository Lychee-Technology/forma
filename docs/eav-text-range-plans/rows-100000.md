# Recorded run of the #815 benchmark, N = 100,000

`TestMixedEAVTextRangePlans` wrote everything below the line, unedited, with
`FORMA_EAV_PLAN_EVIDENCE` set, in the recorded run that
[Text ranges on mixed EAV attributes](../eav-text-range-plans.md) reads. The
dataset, statistics states and probes are described in its
[How it was measured](../eav-text-range-plans.md#how-it-was-measured).

- Revision: `9fa2824e070ad11cf7bd07b714ddc546ba545402`.
  It changes only the benchmark's test code; the repository's SQL generation and `init-db` are those of `main` at
  `bfeead9`.
- Command: `FORMA_EAV_PLAN_EVIDENCE=<dir> FORMA_EAV_PLAN_ROWS=20000,100000
  go test ./internal/e2e_harness/production/ -tags=e2e
  -run TestMixedEAVTextRangePlans -v -count=1`, Go toolchain go1.26.0.
- Each section under "Plans" is the SQL the repository sent, its arguments
  in order, and PostgreSQL's `EXPLAIN (ANALYZE, BUFFERS)` text. That plan is
  its own execution, run just before the JSON one the "Results" row reads, so
  its times, and rarely its buffers, differ slightly from that row's.
- "scan output rows" are what the plan's scans of each relation returned
  after their filters (Actual Rows × Loops). "rows filtered by scans" are the
  rows those scans read and discarded by a Filter or an index recheck (Rows
  Removed by Filter or by Index Recheck × Loops). Neither counts index
  entries a btree passes over inside an Index Cond; buffers measure the
  plan's whole work. Relations with no such rows are left out.
- Times are indicative only (a shared machine); read estimates and buffers
  as the evidence.

```sql
WITH anchor AS (
	            SELECT DISTINCT t.row_id
	            FROM "eav_data" t
	            WHERE t.schema_id = $1 AND (EXISTS (SELECT 1 FROM "eav_data" x WHERE x.schema_id = t.schema_id AND x.row_id = t.row_id AND x.attr_id = $2 AND x.value_text > $3))
	            UNION
	            -- Include real-time buffer rows from change_log (flushed_at = 0)
	            -- while preserving the same anchor filter semantics.
	            SELECT cl.row_id
	            FROM "change_log" cl
	            WHERE cl.schema_id = $1
	                AND cl.flushed_at = 0
	                AND EXISTS (
	                    SELECT 1
	                    FROM "eav_data" t
	                    WHERE t.schema_id = $1
	                        AND t.row_id = cl.row_id
	                        AND (EXISTS (SELECT 1 FROM "eav_data" x WHERE x.schema_id = t.schema_id AND x.row_id = t.row_id AND x.attr_id = $2 AND x.value_text > $3))
	                )
	        ),
        keys AS (
            SELECT
                a.row_id,
                COUNT(*) OVER() AS total
            FROM anchor a
        ),
        ordered AS (
            SELECT
                row_id,
                total
            FROM keys
            ORDER BY
                row_id
            LIMIT $4 OFFSET $5
        ),
        main_data AS (
            SELECT
                ltbase_schema_id, ltbase_row_id, ltbase_created_at, ltbase_updated_at, ltbase_deleted_at, ltbase_created_by, ltbase_deleted_by, ltbase_updated_by, text_01, text_02, text_03, text_04, text_05, text_06, text_07, text_08, text_09, text_10, smallint_01, smallint_02, smallint_03, integer_01, integer_02, integer_03, bigint_01, bigint_02, bigint_03, double_01, double_02, double_03, uuid_01, uuid_02,
                o.total
            FROM ordered o
            INNER JOIN "entity_main" m
                ON m.ltbase_schema_id = $1
                AND m.ltbase_row_id = o.row_id
        ),
        eav_aggregated AS (
            SELECT
                e.row_id,
                JSON_AGG(
                    JSON_BUILD_OBJECT(
                        'schema_id', e.schema_id,
                        'row_id', e.row_id,
                        'attr_id', e.attr_id,
                        'array_indices', e.array_indices,
                        'value_text', e.value_text,
                        'value_numeric', e.value_numeric
                    ) ORDER BY e.attr_id, e.array_indices
                )::TEXT AS attributes_json
            FROM ordered o
            INNER JOIN "eav_data" e
                ON e.schema_id = $1
                AND e.row_id = o.row_id
            GROUP BY e.row_id
        )
        SELECT
            ltbase_schema_id, ltbase_row_id, ltbase_created_at, ltbase_updated_at, ltbase_deleted_at, ltbase_created_by, ltbase_deleted_by, ltbase_updated_by, text_01, text_02, text_03, text_04, text_05, text_06, text_07, text_08, text_09, text_10, smallint_01, smallint_02, smallint_03, integer_01, integer_02, integer_03, bigint_01, bigint_02, bigint_03, double_01, double_02, double_03, uuid_01, uuid_02,
            COALESCE(e.attributes_json, '[]') AS attributes_json,
            m.total AS total_records,
            CEIL(m.total::numeric / NULLIF($4::numeric, 0)) AS total_pages,
            (FLOOR($5::numeric / NULLIF($4::numeric, 0)) + 1)::int AS current_page
        FROM main_data m
        LEFT JOIN eav_aggregated e ON e.row_id = m.ltbase_row_id
        ORDER BY
            m.ltbase_row_id;
```
