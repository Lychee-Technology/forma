# Format: <origin> <rule> <#issue> <note>

# Each line accepts the dsql-lint diagnostics of one rule on statements of one
# generator (an inventory location classified rendered), because the issue
# named tracks fixing them. It accepts nothing else: a new rule on the same
# generator, or the same rule on another generator, still fails the gate, and
# there is no way to disable a rule globally. A line whose finding no longer
# occurs fails the gate as stale, so fixing the generator forces its removal.
