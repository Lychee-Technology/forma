# Inventory of every place in Forma's code that holds or sends SQL (#740).
#
# Format: <class> <location> <note>
#         gap <name> <tracking> <note>
#
#   location   path/file.go:Symbol (function, Type.Method, or package-level
#              const/var/type), path/file.go:* (every symbol of the file),
#              or a checked-in path/file.sql.
#   class      rendered       a TestDSQLCorpus* test renders it and the DSQL
#                             lint gate lints it; must appear as a corpus origin
#              uncovered      can reach Aurora DSQL but is not linted; the note
#                             starts with its [gap] and says why
#              passthrough    sends, forwards or declares SQL that another
#                             entry builds; the note names it
#              postgres-only  runs only under the PostgreSQL engine; kept out of
#                             the DSQL corpus
#              duckdb         sent to DuckDB, never to PostgreSQL or DSQL
#              not-dsql       never sent to a DSQL database (test harnesses,
#                             local tools, text that only looks like SQL, a
#                             method that only shares a database method's name)
#   gap        declares a group of uncovered entries and what tracks closing
#              it: an issue (#123), or dsql-lint-coverage-follow-up, the DSQL
#              lint coverage follow-up issue, which lists every such gap by
#              name with its entries. A gap with no entry is refused.
#
# The inventory guard (TestInventoryCoversRepository, run by make test and by
# make lint-dsql) scans every non-test Go file. It fails on any symbol not
# listed here that holds SQL text (a literal, or a constant folded from
# literals and the package's string constants, in any letter case, after
# leading SQL comments, read as written and as SQL tokens, so SELECT(1)
# counts), calls a database method (Exec, Query, QueryRow,
# Begin, BeginTx, SendBatch, CopyFrom, Prepare, Queue and their Context
# forms), or names pgx or database/sql transaction options. It also fails on
# an entry whose symbol is gone, and on an entry other than rendered whose
# symbol is no longer a site. See docs/dsql-lint.md.
