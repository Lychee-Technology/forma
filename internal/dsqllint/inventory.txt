# Format: <class> <location> <note>
#
#   location   path/file.go:Symbol (function, Type.Method, or package-level

#              checked-in path/file.sql.
#   class      rendered       a TestDSQLCorpus test renders it and the DSQL lint
#                             gate lints it; must appear as a corpus origin
#              uncovered      can reach Aurora DSQL but is not linted; the note

#                             the DSQL corpus
#              duckdb         sent to DuckDB, never to PostgreSQL or DSQL
#              not-dsql       never sent to a DSQL database (test harnesses,
#                             local tools, text that only looks like SQL)
#

# make lint-dsql) scans every non-test Go file for string literals that start
# a SQL statement and fails on any symbol holding one that is not listed here,
# on an entry whose symbol is gone, and on an entry (other than rendered) whose
# symbol no longer holds SQL. The scan is a keyword heuristic: SQL assembled
# only from fragments that do not start with a statement keyword evades it.
# See docs/dsql-lint.md.
